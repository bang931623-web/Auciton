기한임박 경매 보드

법원경매 · 온비드 공매 감시 결과
예시 데이터를 보고 있습니다 — 실제 물건이 아닙니다. 파일을 이 화면 아무 곳에나 끌어다 놓아도 됩니다
여기서 추가한 행은 이 브라우저에만 쌓입니다. 노션 설정 DB에 실제로 넣으려면 JSON을 복사해 add_watch.py로 밀어 넣으세요.
data.json 포맷 — sync.py 결과를 이 보드로 넘기는 방법

보드는 노션을 직접 호출하지 않습니다. 브라우저에서 api.notion.com을 부르면 CORS에 막히기 때문에, export_json.py가 노션 DB 세 개를 읽어 data.json 한 장으로 떨어뜨리고 이 화면이 그걸 읽습니다. 칸 이름은 노션 스키마와 글자 그대로 같습니다.

파일 구조

{
  "generated_at": "2026-09-19T14:05:00+09:00",
  "auction": [ /* 기한 임박 물건 (RESULT_SCHEMA) */ ],
  "onbid":   [ /* 공매 물건 (ONBID_SCHEMA) */ ],
  "watch":   [ /* 감시 부동산 (CONFIG_SCHEMA) */ ]
}

}

평당 최저가

전유면적(숫자 ㎡)이 있으면 그 값으로, 없으면 면적 문자열에서 전유 84.23㎡ 꼴을 찾아 계산합니다. 1평 = 3.305785㎡. 경매는 최저매각가격을, 공매는 최저입찰가를 평수로 나눕니다. 둘 다 못 구하면 칸이 비고, 정렬하면 맨 뒤로 갑니다. export_json.py가 전유면적을 자동으로 붙여 내보내므로 노션 스키마는 손대지 않아도 됩니다.

감시 부동산 추가

감시 부동산 탭의 + 감시 부동산 추가로 넣은 행은 이 브라우저에만 쌓이고 노션 미반영 표시가 붙습니다. 노션에 보낼 JSON 복사로 그 행들만 배열로 복사해 파일로 저장한 뒤 python add_watch.py new.json을 돌리면 설정 DB에 실제 행이 생깁니다. 다음 sync.py 실행부터 감시가 시작되고, 지역코드는 첫 조회에서 자동으로 채워집니다.

읽는 규칙

비어 있는 값은 null이나 빈 문자열 어느 쪽이어도 됩니다. 금액은 원 단위 정수로 주면 보드가 억·만 단위로 줄여 보여줍니다. 날짜는 YYYY-MM-DD. 최저가율은 노션이 percent 타입이라 0.49로 저장돼 있는데, 49로 줘도 같게 읽습니다. 이 셋 중 없는 표는 빼도 되고, 그러면 해당 탭이 비어 보입니다.

감정평가액·최저매각가격은 법원 공고 기준이며, 입찰 전 매각물건명세서를 직접 확인해야 합니다.
